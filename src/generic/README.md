## Generic module (src/generic)

This module is a place for code that is not specific to the Learning app.  It is intended to be reusable and we expect we can extract it to a reusable code repository like Paragon or frontend-base in the future.

Take care when changing this code that it doesn't take on domain-specific logic.

Code that is specific to the Learning app, but is shared by multiple top level components belongs in the shared module.
